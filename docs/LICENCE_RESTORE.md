# 5tratMux licence backup and restore

Requires 5tratumOS 0.8.9 and the separately signed 5tratMux 0.9.52 runtime
(or their matching DEV releases), plus internet access during restoration.

1. On the licensed PC, open **Settings → 5tratMux Licence → Back up or restore licence**.
2. Download the licence proof and save it somewhere outside that PC before reinstalling or replacing it.
3. On the replacement PC, open the same panel and upload the saved proof.
4. Confirm the move and download the latest proof for your backup.

The proof is a signed JSON file containing a recovery secret, not an encrypted
backup. Anyone with the file may be able to move your licence. Keep it private;
do not post it publicly or include it in diagnostic uploads.

A paid licence allows five self-service moves in total. Moving it preserves the
original plan and expiry date; it does not restart the purchased period. The
panel shows how many moves remain. Retrying a completed restore on the current
installation does not consume an additional move. After the allowance is used,
contact support for help rather than purchasing a replacement by mistake.

The previous installation loses paid access at its next online licence check
or when its already-issued offline access expires. A disconnected PC cannot be
disabled instantly. Only the current binding can renew paid access.

If you no longer have the proof, contact support with your original purchase
details. A new installation request identifies the new installation; it does
not show the old licence's purchased term or prove ownership by itself.
