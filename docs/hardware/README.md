## Contributing a new model

If your model isn't listed, a great contribution is:

- model name (and any sub-model)
- BIOS/UEFI version
- which key opens BIOS and the boot menu
- screenshots or exact menu paths for Secure Boot / UEFI / AHCI / VMD
