These files are used to brand the installer ISO boot UX.

- `isolinux/splash.png` is used by the legacy BIOS boot menu and also as the GRUB theme background on some UEFI firmware.
- `grub/background.png` is injected as the GRUB menu background (when present).

These images are generated from the primary brand assets under `overlay/portal/assets/New Logos/`:

- `WordOnlyLogo.png`
- `5.png`

Preferred format: PNG24 (8-bit per channel RGB, no alpha).
