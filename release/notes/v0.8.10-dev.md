# 5tratumOS 0.8.10 DEV — Local AI recovery

DEV channel build with the same OS and managed Local AI changes as 0.8.10
MAIN. Signed Local AI runtime **0.1.3** upgrades existing public 0.1.0, 0.1.1
and 0.1.2 installations in place only when 5tratumOS still owns and enables
them. Downloaded models, selection, resource preferences, storage and prior
On/Off intent are preserved, with rollback if the replacement fails to start.

The OS-owned updater installs the separately signed **5tratMux 0.9.54-dev**.
It repairs multi-address research networking, adds safe failure diagnostics and
restores explicit model switching. Private, disabled, cross-platform,
differently owned and unknown Local AI configurations remain untouched.

No new bootable media is included. The OS archive retains the established
SHA-256 mechanism; Local AI and native MUX metadata are independently signed.
