# 5tratumOS 0.8.10 — Local AI recovery

This update adds the signed managed Local AI **0.1.3** runtime and the safe
in-place upgrade path used by 5tratMux 0.9.54. Existing public 0.1.0, 0.1.1 and
0.1.2 installations are upgraded only when they are still owned and enabled by
5tratumOS. Downloaded models, the selected model, resource preferences,
container identity, storage volume and previous On/Off intent are preserved.

The host verifies the replacement image before stopping the old runtime. If the
replacement cannot start, it restores the previous owned container and running
state. Private, disabled, cross-platform, differently owned and unknown Local
AI configurations are left untouched.

This bundle installs the separately signed **5tratMux 0.9.54** through the
OS-owned updater. That release repairs multi-address research networking,
improves safe failure diagnostics and restores explicit model switching.
The Raspberry Pi image was refreshed on 23 September to install 0.8.10 directly;
AMD/Intel UEFI and BIOS media remain at 0.8.7. See the RPi refresh notes below.

The OS archive uses the established SHA-256 checksum mechanism. Local AI and
native MUX metadata are independently signed; this does not sign the OS
archive.

OS source: `WillItMod/5tratum_Build` commit `a9e1f8b2170f7eb966ffd3cf7d0ce50a55a0ee35`.
MUX source: `WillItMod/5tratMux_Build` commit `3b589bb6c2ea7c45da38cd7556cb9caec9b55121`.
