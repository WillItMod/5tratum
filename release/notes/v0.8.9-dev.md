# 5tratumOS 0.8.9 DEV — licence backup and restore

DEV channel build with the same OS changes as 0.8.9 MAIN. Open **Settings →
5tratMux Licence → Back up or restore licence** in Classic or Orbit. Save the
proof outside the PC and upload it after a reinstall or on a replacement PC.
Paid licences support five self-service moves, preserving the original plan
and expiry. Keep the proof private because it contains the recovery secret.

The previous installation's paid binding is retired on each move. It stops
at its next online check or when existing offline access expires, not instantly
while disconnected.

The OS-owned updater installs the separately signed **5tratMux 0.9.52-dev**.
This retains the 0.8.8 handoff fix and current feature packaging. No new
bootable media is included. The OS archive retains the established SHA-256
mechanism; its native MUX release manifest is independently signed.
